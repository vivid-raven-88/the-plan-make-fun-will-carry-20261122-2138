A program that writes one text to `/output/entry.txt`: a concrete plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## How it works

`main.ts` (Node 22) builds the plan text and writes it to `/output/entry.txt`. It is deterministic — no network calls, no randomness, no environment reads — so running it twice produces byte-identical output.

## The plan in one line

Sell $49 "landing page in 24 hours" gigs to small businesses found on Google Maps with no website, at $49 per job rising to $79, reaching about $700 by day 30.
